# Roadmap

Each task here is a choice of the owner. A task leaves this list when its
release is out. The reason for each choice is in
[docs/decisions.md](docs/decisions.md).

## v2.7: Tracking

- [#23](https://github.com/Stiven-Gjekaj/Asabunko/issues/23) Track the progress with AniList and MyAnimeList
- [#24](https://github.com/Stiven-Gjekaj/Asabunko/issues/24) Send the progress to Komga and Kavita

## v2.8: The platform

- [#25](https://github.com/Stiven-Gjekaj/Asabunko/issues/25) Translate the app
- [#26](https://github.com/Stiven-Gjekaj/Asabunko/issues/26) Add a widget for continue reading
- [#27](https://github.com/Stiven-Gjekaj/Asabunko/issues/27) Open files from the Files app and share books
- [#28](https://github.com/Stiven-Gjekaj/Asabunko/issues/28) Add haptics and fix the look on iPad

## v3.0: Quality

- [#29](https://github.com/Stiven-Gjekaj/Asabunko/issues/29) Run the full UI suite before each release
- [#30](https://github.com/Stiven-Gjekaj/Asabunko/issues/30) Check the app with VoiceOver and Dynamic Type

## Not on the list

- The search of Toonkotsu gives no titles. This is a fault of the source.
- Mac Catalyst and visionOS. The app is for iPhone and iPad.
- iCloud sync. A sideload with a free Apple ID cannot use iCloud.
